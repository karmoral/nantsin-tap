Guía de Despliegue

Cómo subir este proyecto a GitHub Pages

Sigue estos sencillos pasos para alojar tu página web de forma gratuita con GitHub.

1

Crear un repositorio en GitHub

Inicia sesión en GitHub, haz clic en New, asígnale un nombre (ej. catalogo-whatsapp) y déjalo como Public.

2

Guardar este código como index.html

Crea un archivo local con el nombre exacto index.html y pega todo el código completo de esta aplicación.

3

Subir el archivo

En tu repositorio, haz clic en upload an existing file, arrastra tu index.html y haz clic en Commit changes.

4

Activar GitHub Pages

Ve a Settings > Pages. En Build and deployment selecciona la rama main y guarda.

5

¡Listo!

GitHub te dará una URL pública donde tus clientes podrán ver las imágenes, títulos, descripciones y apartar directo al WhatsApp 5584038535.
